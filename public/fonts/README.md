# Self-hosted fonts

These Latin-subset WOFF2 files are bundled so `next build` never depends on
Google Fonts at build time.

| File | Family | Source | Licence |
|---|---|---|---|
| `cormorant-garamond-latin.woff2` | Cormorant Garamond | Google Fonts | SIL Open Font License 1.1 |
| `plus-jakarta-sans-latin.woff2` | Plus Jakarta Sans | Google Fonts | SIL Open Font License 1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | Google Fonts | SIL Open Font License 1.1 |
